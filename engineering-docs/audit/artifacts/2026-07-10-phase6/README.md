# Phase 6 Local Profile Artifacts

This directory contains local-only Go CPU, heap, and block profiles produced by the
2026-07-10 Oversync assurance audit. They are historical diagnostic evidence,
not current performance baselines, CI inputs, runtime assets, or production
SLOs.

The source audit journal is retained in Git history rather than active
documentation. Its exact Phase 6 commands and environment can be inspected
with:

```bash
git show e08879263c44934c1470084a8792c301f17bb0df:engineering-docs/audit/2026-07-10-oversync-assurance.md
```

See `engineering-docs/assurance/README.md` for the maintained assurance and
validation policy.
